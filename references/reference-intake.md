# Adding documents the user provides

Use this whenever the user uploads or points to a standard, handbook chapter, procedure, test report, photo or manufacturer note.

1. **Log it** in `references/library/INDEX.md`: title, edition and year, which pages or sections, who owns it, whether it is confidential or may be redistributed, and what it is good for. Never copy a paywalled or confidential document into the skill's shared folders unless the user says it is allowed; keep the file path and the log entry.
2. **Identify the document from its title pages, not its file name** (edition, volume, year, what it covers and omits). **Read the first page and the relevant sections**, not only a summary. For books use `python3 scripts/book-search.py <book.pdf> find "regex"` and `show <page> --to <page> --printed`; it reports the PRINTED page number of each page, which is what a citation needs. Note the exact edition. Record `read: full` or `read: excerpt` (with pages) in `claims/sources.json`.
3. **Extract facts as claims**, not as pasted text. One claim per fact, in your own words, with page numbers in `note` (for example "p. 38, Table 2"). Cite a page as `"source-id:page"` in `sources`. Check any number against the page image before recording it (`pdftoppm -jpeg -r 120 -f N -l N -x X -y Y -W W -H H book.pdf /tmp/crop`, then view it); scanned books especially. Numbers go in only with `numbers_ok: true` and the page that states them, with units and the conditions (material, thickness, process, polarity, gas).
4. **Resolve conflicts explicitly.** If two documents disagree, keep both in a `note`, prefer the governing code the user names, and raise it with the expert; do not average.
5. **Update the right reference file** (`processes/*.md`, `physics-and-metallurgy.md`, `defects.md`, `standards-glossary.md`, `proportions.md`) so the knowledge survives beyond one figure. Mark each entry's status: `from document` (page), `from memory (verify)`, or `open question`.
6. **Photos and macros**: put them in `assets/` with a caption file giving process, material, thickness, conditions and what the image shows. Use them to set proportions and appearance (nugget size against electrode face, HAZ width, crown height), and record the resulting rule in `proportions.md`.
7. **Say what you did not read.** If a document was too long to read in full, list the sections used and the sections skipped.
